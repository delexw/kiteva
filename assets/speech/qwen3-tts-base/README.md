# Default Base reference voices

These two synthetic reference recordings are Kiteva defaults, not built-in Qwen Base speakers. Generated locally with Qwen3-TTS-12Hz-1.7B-VoiceDesign using the female and male Broadcast narrator profiles. These two defaults do not use a third-party speaker recording.

The exact spoken text is in reference-text.txt and the shared Base voice catalog. Both references can condition Chinese and English output. Base does not support VoiceDesign descriptions or the CustomVoice named speaker list. Update the catalog revision when replacing a reference recording.

`original-narrator.wav` is a 10.4-second reference excerpt from the user-supplied video, isolated from its background audio and bundled at the user's request. Its exact transcript is in the shared Base voice catalog. It is separate from the two synthetic defaults above.
